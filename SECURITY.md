# Security policy

If you find a security issue, please **do not open a public issue**. Contact the author privately through [LinkedIn](https://www.linkedin.com/in/james-ehlert-reinard/) with a short description and steps to reproduce.

This repository never contains secrets, certificates, account IDs, endpoints or personal data. It is generated from a private repository by an exporter that uses an allowlist, a list of forbidden values kept outside any repository, secret-pattern scanning and a self-test before every publication. GitHub push protection and secret scanning are enabled as an extra layer.
